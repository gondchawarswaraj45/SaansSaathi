SECTION A: OVERALL DESIGN DIRECTION
================================================================================

DESIGN PHILOSOPHY:
  "Information-first with emotional clarity"
  - Users should understand air quality status in under 3 seconds
  - Color should communicate danger, not just decorate
  - Family-focused tone (warm, protective, not clinical)

RECOMMENDED COLOR PALETTE:
  Primary:        #2D6A4F (Forest Green - clean air, nature, safety)
  Secondary:      #40B4C4 (Sky Blue - fresh air, openness)
  Accent:         #F4A261 (Warm Amber - alerts, attention)
  Background:     #F8FAF9 (Off-white with green tint)
  Card:           #FFFFFF
  Text Primary:   #1A1A2E
  Text Secondary: #6B7280

AQI-SPECIFIC COLORS (Indian CPCB Standard):
  Good (0-50):         #55A630 (Green)
  Satisfactory (51-100): #A7C957 (Light Green)
  Moderate (101-200):  #F4A261 (Amber)
  Poor (201-300):      #E76F51 (Orange)
  Very Poor (301-400): #D62828 (Red)
  Severe (401-500):    #6B0504 (Dark Red/Maroon)

TYPOGRAPHY:
  Primary Font:   Inter (Google Fonts - clean, readable)
  Fallback:       system-ui, -apple-system, sans-serif
  Heading:        Inter Bold 700
  Subheading:     Inter SemiBold 600
  Body:           Inter Regular 400
  Code/Data:      JetBrains Mono (for AQI numbers)

================================================================================
SECTION B: DASHBOARD PAGE DESIGN
================================================================================

HERO CARD (top-center, full attention):
  - Large circular AQI gauge (donut chart style, 150px diameter)
  - Center: AQI number in bold (40px, JetBrains Mono)
  - Below number: Category text (Moderate / Poor / etc.)
  - Card background gradient matches AQI category color
  - Animated pulse ring around gauge for live data indicator
  - Bottom: "📍 Bavdhan, Pune | Station: Pashan | Updated 5 min ago"
  REFERENCE: Image 7 (AQI.in) shows this exact pattern - large AQI indicator
              in top-left corner with category label

POLLUTANT BREAKDOWN GRID:
  - 6 mini-cards in 2x3 grid (or 3x2 on desktop)
  - Each card: Pollutant name | Value + unit | Thin progress bar
  - Progress bar fills from green → red based on safe limit %
  - Hover tooltip: "Safe limit: 60 μg/m³ (WHO: 15 μg/m³)"
  REFERENCE: Image 6 (ICCC Jaipur popup) shows exact pollutant list format

TREND CHART:
  - Area chart (not line chart) - fills under curve with gradient
  - Gradient: green at bottom, transitions to red at top based on value
  - X-axis: time (last 24h in hourly ticks)
  - Y-axis: AQI 0-500 with category threshold lines
  - Threshold reference lines (dashed): at 100, 200, 300, 400
  - Toggle: 24H | 7D | 30D (pill buttons, not tabs)
  REFERENCE: Image 7 (AQI.in) has PM10 and PM2.5 variation charts

WEATHER WIDGET:
  - Small card bottom-right of dashboard
  - Temperature, humidity, wind speed+direction, UV index
  - Wind direction shown as compass arrow (not text)
  - "These conditions affect pollution dispersal" info tooltip

LOCATION SELECTOR:
  - Top of dashboard, sticky on scroll
  - Shows city name + search icon
  - GPS button (crosshair icon) for auto-detect
  - Clicking opens modal with city search + saved locations list

SECTION C: MAP PAGE DESIGN
================================================================================

RECOMMENDED MAP APPROACH (Based on reference images):

Option A - Pin Map (Recommended for MVP):
  - Individual pins per monitoring station (like Images 1, 7, 8)
  - Each pin is a colored rounded rectangle with AQI number
  - Pin color = AQI category color
  - Clicking pin opens bottom sheet (mobile) or sidebar popup (desktop)
  - OpenStreetMap base tiles (clean, light theme)

Option B - Heatmap Overlay (Advanced):
  - Like Images 3, 4 - colored overlay across the region
  - Requires interpolation between station readings
  - IMPORTANT: Must label this as "estimated" not "measured"
  - Use lighter opacity (0.4-0.5) so map roads remain visible

RECOMMENDED: Start with Option A (Pin Map) for accuracy and trust.

MAP LAYOUT:
  - Full-page map (no sidebar stealing space on mobile)
  - Floating panel: top-left = search bar, bottom-left = legend
  - Desktop: right panel slides in when station is clicked
  - Mobile: bottom sheet slides up when station is clicked
  - "My Location" button: bottom-right floating button
  - Zoom controls: standard + and - top-right (default Leaflet)

PIN DESIGN:
  - Rounded rectangle shape (like Image 7, 8)
  - 48px × 36px minimum touch target
  - White text on colored background
  - Drop shadow for depth
  - Number font: JetBrains Mono Bold

STATION POPUP CONTENT:
  - Station name (bold, 16px)
  - AQI number + category badge
  - PM2.5, PM10, NO2 values
  - Last updated time (with "LIVE" badge if < 1 hour old)
  - "Set as my location" button
  REFERENCE: Image 6 (ICCC Jaipur) shows exact popup format

LEGEND (bottom of map):
  - Horizontal color scale (like all reference images)
  - Good | Moderate | Unhealthy for SG | Unhealthy | Very Unhealthy | Hazardous
  - Color boxes with text labels
  - Semi-transparent background card

SECTION E: MOBILE-FIRST DESIGN RULES
================================================================================

MOBILE NAVIGATION:
  - Bottom navigation bar (5 tabs): Dashboard | Map | Family | AI Chat | More
  - NOT a hamburger menu (too many taps)
  - Active tab highlighted in primary green
  - Icons + labels (no icon-only - accessibility)

TOUCH TARGETS:
  - Minimum 44×44px for all tappable elements
  - AQI pins on map: minimum 48×36px
  - Form inputs: minimum 44px height

MOBILE DASHBOARD LAYOUT:
  - Single column, full-width cards
  - Swipeable horizontal scroll for pollutant cards
  - Collapsible sections for less critical info
  - Fixed bottom CTA: "Ask AI Assistant" floating button

PERFORMANCE ON MOBILE:
  - Lazy load charts (only load Recharts when card is in viewport)
  - Compress map tiles (use CartoDB Positron tiles - lighter than OSM default)
  - Paginate notifications (max 20 per page)
  - Cache API responses in localStorage (with TTL)

SECTION G: ANIMATIONS & MICRO-INTERACTIONS
================================================================================

USE THESE ANIMATIONS:
  1. AQI number count-up animation (0 → actual value over 1 second)
     - Makes the number feel "live"
     - Use framer-motion or CSS animation
  
  2. Pulsing ring on "LIVE" indicator
     - Subtle pulse every 3 seconds
     - Green ring for good AQI, red for bad
  
  3. Map marker bounce on click
     - Standard Leaflet marker bounce
  
  4. Card hover lift effect (transform: translateY(-2px))
     - Subtle shadow increase on hover
  
  5. Progress bar fill animation (0 → actual on load)
     - CSS transition: width 0.8s ease-out

AVOID:
  - Heavy scroll animations (reduces performance)
  - Full-page transitions (confusing on mobile)
  - Auto-playing videos
  - Excessive particle effects

================================================================================
SECTION H: ACCESSIBILITY REQUIREMENTS
================================================================================

MUST IMPLEMENT:
  - Color is NEVER the ONLY indicator (always add text label too)
    Example: Don't just show red pin - show "346 - Very Unhealthy"
  - All images have descriptive alt text
  - Form inputs have associated labels (not just placeholder)
  - Keyboard navigation works for all interactions
  - Focus indicators are visible (don't remove outline)
  - Min font size: 16px for body text (no smaller)
  - Color contrast ratio: 4.5:1 minimum (WCAG AA)
  - Screen reader announcements for AQI changes (aria-live)

TOOLS TO CHECK:
  - axe-core browser extension (free)
  - Lighthouse Accessibility audit (built into Chrome DevTools)
  - Target score: 90+
